Python Encryption and Decryption Program

This program demonstrates two types of encryption: symmetric encryption and asymmetric encryption. It allows users to enter a short message, encrypts the message using both methods, and then decrypts it to display the original message.

The purpose of this program is to demonstrate how symmetric and asymmetric encryption work and explain the differences between using one secret key and using a public/private key pair. The encryption keys are generated each time the program runs and are not saved for future use.
